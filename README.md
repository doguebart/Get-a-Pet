## 🇧🇷 Português <a name="portugues"></a>

Get a Pet é uma plataforma inovadora que conecta ONGs e pet shops com pessoas interessadas em adotar animais. Desenvolvido utilizando os princípios do SOLID, o sistema é robusto, escalável e de fácil manutenção.

### Tecnologias Utilizadas 🛠
- Princípios do SOLID
- Node.js
- TypeScript
- Fastify
- Fastify JWT
- Fastify Cookies
- PostgreSQL
- Prisma
- Docker
- Zod
- Bcryptjs
- Testes unitários com Vitest

### Funcionalidades 🧬
- [x] **Cadastro de Org**
- [x] **Autenticação de Org**
- [x] **Gerenciamento das informações da Org**
- [x] **Cadastro de Animais pela Org**
- [x] **Gerenciamento de Animais pela Org**
- [x] **Atualização do Status de Adoção de um Animal**
- [x] **Visualização dos Detalhes de uma Org**
- [x] **Listagem de Todos os Animais**
- [x] **Listagem de Todos os Animais de uma Org**
- [x] **Filtro de Animais pelo Nome**
- [x] **Visualização dos Detalhes de um Animal**
